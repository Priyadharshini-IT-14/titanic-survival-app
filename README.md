# Titanic Survival Predictor

A small web app built with Streamlit. It uses a decision tree (trained in my Project 4) to estimate a passenger's chance of survival from ticket class, sex, age and fare.

**Model:** DecisionTreeClassifier, max_depth=4, trained on the Titanic dataset from seaborn.
**Educational example only.** It describes a historical dataset and is not advice.
**Files:** app.py (the app), model.joblib (the saved model), requirements.txt (packages).
